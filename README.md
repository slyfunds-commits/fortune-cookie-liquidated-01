One fortune cookie line for a crypto trader who has just been liquidated —
a classic fortune opener hijacked so the last beat recontextualises the loss.
Entry for the [Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c)
bounty on [make.fun](https://make.fun).

> Fortune favours the bold. It liquidated the bold at 41,273 and kept the change.

14 words, 79 characters. The keeper passed the full judge-list-max gate
(all 12 checklist items + 5/5 likes + zero dislikes + P10 familiar-phrase
hijack + P12 echo-close + P13 numbers ledger), screened from 354 candidates
across 7 premise families. The fortune voice, the loss, and the trader are all
in the line; the joke lands on the loss, rueful and warm — the cookie is on
the trader's side against the market.

## Run

```sh
python3 main.py
```

Writes the keeper verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `output/`
if unset). Pure Python standard library, deterministic, no trailing newline.
